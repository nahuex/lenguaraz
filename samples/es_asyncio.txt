# Transcripción de referencia para samples/es_asyncio.wav — una oración por línea. Apache-2.0.
Buenas tardes a todos y gracias por venir al taller.
Hoy vamos a construir un servicio de subtítulos en tiempo real con Python y asyncio.
Cada escenario de la conferencia tiene su propio TaskGroup y su propia cola con backpressure.
Para transcribir usamos la API Live de Gemini, que devuelve hipótesis parciales y resultados finales.
Las sesiones duran diez minutos, así que rotamos la conexión sin perder ninguna frase.
El glosario de la charla mejora nombres como Kubernetes, eBPF o Nerdearla.
Todo el código está publicado bajo licencia Apache dos punto cero.
