## 3. Design

```
stages.yaml + .env ─▶ config.Settings / StagesFile (pydantic)
                              │
                     StageManager (api lifespan)
                              │ one per stage
                         StageRunner ── asyncio.TaskGroup ──┐
   source ─▶ AudioSource (ingest/wav.py | ingest/ffmpeg.py) │  3,200-byte chunks, real-time paced
                              │ Queue(maxsize=50)           │
                     ManagedSttSession (stt/session.py)     │  reconnect/backoff, seq, latency, state
                              │ SttEngine.open() → SttSession (stt/gemini.py | stt/fake.py)
                              │ SttEvent(interim|final|go_away|usage|error)
                         MemoryBus.publish(stage_id, CaptionEvent|StatusEvent|MetricsEvent)
                              │ bounded per-subscriber queues (drop oldest interim, keep finals/status)
                    api/ws.py  WS /ws/{stage}?lang=   ─▶ browser (web/: Home, Fogón)
                    api/app.py GET /healthz, /api/stages, static SPA
```

**Package layout** (`lenguaraz/`, technical names inside, surface names in UI/docs/metrics):
- `config.py` — `Settings` (pydantic-settings, env) and `StagesFile`/`StageConfig` (YAML; validators: unique ids, non-empty source, BCP-47 shape, targets short codes, glossary ≤ 100).
- `models.py` — `StageState` enum, `Segment`, `CaptionEvent`, `StatusEvent`, `MetricsEvent` (pydantic, `type` discriminator), `WsCloseCode` constants (4404 unknown stage, 4429 rate limited).
- `ingest/base.py` — `AudioSource` protocol (`chunks() -> AsyncIterator[bytes]`, `close()`); `ingest/wav.py` — `WavFileSource` (stdlib `wave`, real-time pacing, used for `.wav` sources and in dry run so the fresh-clone test needs no ffmpeg); `ingest/ffmpeg.py` — `FfmpegSource` (`ffmpeg -hide_banner -loglevel error [-re] -i <src> -vn -ac 1 -ar 16000 -f s16le -` read from stdout in 3,200-byte frames; `terminate()` then `kill()` after 2 s).
- `stt/base.py` — `SttEngine` (`open(stage) -> SttSession`), `SttSession` (`send(chunk)`, `end_of_stream()`, `events()`, `close()`), `SttEvent`.
- `stt/gemini.py` — `GeminiSttEngine`: builds `LiveConnectConfig` from stage + settings; sender task forwards chunks with `send_realtime_input(audio=Blob(...))`; receiver maps `server_content.interim_input_transcription` → interim, `input_transcription` → final, `go_away` → go_away, `usage_metadata` → usage; `errors.APIError` → error event with `.code`.
- `stt/fake.py` — `FakeSttEngine` (dry run: emits word-by-word interims and sentence finals from the reference `.txt`/`.json` next to the sample, paced to the audio bytes it receives) and `ScriptedSttSession` (tests: explicit list of `(delay, event)`).
- `stt/session.py` — `ManagedSttSession`: state machine `STARTING → LIVE → (ROTATING|DEGRADED) → LIVE → STOPPED`; reconnect with backoff (0.5 s × 2ⁿ, jitter, cap 10 s, max 5 then `DEGRADED` with detail); assigns `seq` (interims of one utterance share the seq of their final); computes `t_audio_ms` and `latency_ms`; timer-based reopen at `SESSION_ROTATE_SECONDS` (plain close/reopen here; 003 makes it seamless).
- `bus/base.py` — `Bus` protocol (`publish`, `subscribe(stage_id) -> Subscription`); `bus/memory.py` — `MemoryBus` with per-subscription `asyncio.Queue(maxsize=200)`; on full: evict the oldest interim; if none, evict oldest caption but never a final/status (finals are ≤ 1/s so the queue cannot be dominated by them).
- `runner.py` — `StageRunner` (`start()`, `stop()`, `state`), `StageManager` (`start_all()`, `stop_all()`, `snapshot()`); each runner has its own `TaskGroup`; exceptions are caught at the runner boundary and become `DEGRADED`/`STOPPED` with detail.
- `metrics.py` — `LatencyWindow` (deque 200 → p50/p95), counters per stage, `metrics` event every 5 s.
- `api/app.py` — `create_app(settings)`; lifespan starts/stops `StageManager`; `/healthz`, `/api/stages`; mounts `web/dist` with SPA fallback; `api/ws.py` — WS endpoint, per-IP token bucket (10 connections / 10 s), sends `status` first, then forwards bus events filtered by `lang`.
- `logging.py` — JSON formatter with `stage_id`, `session_id`, `seq`, `component`.
- `cli.py` — `lenguaraz serve`, `lenguaraz samples`, `lenguaraz smoke-stt`, `lenguaraz mvp-check` (also `python -m lenguaraz …`).
- `tools/samples.py` — TTS generator: sentence-by-sentence `generate_content` (24 kHz PCM) → concatenate with 800 ms silence → resample to 16 kHz with ffmpeg → `samples/<lang>_<slug>.wav` + `.txt` (reference) + `.json` (sentence boundaries in ms, used to measure true end-of-utterance → final latency).
- `tools/smoke_stt.py` — streams a sample through the real engine, prints finals, WER (jiwer) vs reference, interim p50/p95 and end-of-utterance → final p50/p95 using the `.json` boundaries; appends a dated row to `docs/metrics.md`.
- `tools/mvp_check.py` — starts the app in-process (fake or real), checks MVP-1..7 programmatically (two stages LIVE, captions on both WS, interim + final seen, UI bundle present).
- `scripts/docs_check.py` — cross-checks `Settings` fields and `StageConfig` fields against `docs/configuration.md`; checks relative links in `README.md` and `docs/`.
- `web/` — Vite + React + TS + Tailwind v4; `src/pages/Home.tsx`, `src/pages/Fogon.tsx`; `src/lib/captions.ts` (reconnecting WS with backoff 0.5→8 s, event parsing, interim/final merge); `src/components/{CaptionView,LanguagePicker,A11yControls,DryRunBadge,StageCard}.tsx`; vitest + Testing Library.
- `Dockerfile` (multi-stage: node build → `python:3.12-slim` + uv, ffmpeg installed from Debian, non-root user), `docker-compose.yml` (service `lenguaraz`, env from `.env`, mounts `stages.yaml` and `samples/` read-only, healthcheck on `/healthz`).
- `stages.yaml` (two sample stages) and `examples/stages.minimal.yaml`.

## 4. Contracts
- **Events** (`WS /ws/{stage_id}?lang=`), JSON, one per message, exactly product.md §4; `caption.latency_ms` and `t_audio_ms` defined as: `t_audio_ms` = audio position (bytes sent ÷ 32) of the newest chunk sent before the event; `latency_ms` = `(now − stream_start_wall) − t_audio_ms` = how far captions lag behind the audio timeline. `make smoke-stt` additionally reports end-of-utterance → final latency from the sample boundaries; both are documented in `docs/metrics.md`.
- **HTTP:** `GET /healthz → {"status":"ok","engine":"gemini|fake","stages":N}`; `GET /api/stages → [{id,name,state,detail,source_lang,targets,listeners,dry_run}]`.
- **WS close codes:** 4404 unknown stage · 4400 unsupported `lang` · 4429 rate limited.
- **Config keys** (all documented in `docs/configuration.md`): env `ENGINE`, `GEMINI_API_KEY`, `ADMIN_TOKEN`, `GEMINI_STT_MODEL`, `GEMINI_TRANSLATE_MODEL`, `GEMINI_INTERPRETER_MODEL`, `GEMINI_TTS_MODEL`, `STT_MODE`, `SESSION_ROTATE_SECONDS`, `PROGRESSIVE_TRANSLATION`, `LOG_TRANSCRIPTS`, `REDIS_URL`, `STAGES_FILE`, `HOST`, `PORT`, `LOG_LEVEL`, `WS_MAX_CONN_PER_IP`; YAML `stages[].{id,name,source,source_lang,targets,talk.title,talk.abstract,glossary}`.
- **Python interfaces:** `SttEngine.open(stage: StageConfig) -> SttSession`; `SttSession.send(chunk: bytes)`, `end_of_stream()`, `events() -> AsyncIterator[SttEvent]`, `close()`; `AudioSource.chunks() -> AsyncIterator[bytes]`; `Bus.publish(stage_id, event)`, `Bus.subscribe(stage_id) -> Subscription` (`async for event in sub`, `close()`).

## 6. Risks & mitigations
| Risk | Likelihood | Mitigation |
|---|---|---|
| M1 budget (2h20m) too tight for the whole feature | High | Vertical slice first: config → WAV source → fake engine → bus → WS → minimal Fogón; then Gemini engine + smoke; docs and Docker after the slice |
| Live API rejects a config field or the key lacks access to the transcribe model | Medium | Config built only from verified fields; `smoke-stt` prints the exact `APIError.code/message`; fallback `STT_MODE=VERBATIM` documented |
| Owner's machine: Python 3.14 default, ffmpeg not on PATH for the IDE shell | Medium | `.python-version` = 3.12 (uv installs it); `FFMPEG_BIN` env override; `WavFileSource` needs no ffmpeg |
| Backpressure bug drops a final | Low | `test_bus.py` stress test; eviction policy unit-tested |
| WS clients behind NAT share an IP and hit the rate limit | Medium | Generous default (`WS_MAX_CONN_PER_IP=50`), configurable, documented in troubleshooting |
| TaskGroup cancellation leaves ffmpeg orphans | Medium | `finally: terminate(); wait(2s); kill()`; test asserts process exit |
| Latency definition misunderstood by judges | Medium | Both metrics (timeline lag and end-of-utterance → final) explained in `docs/metrics.md` with method |

## 7. Verification strategy
- **Unit (fakes, no network):** config validation; WAV pacing and chunk size; ffmpeg arg builder + process lifecycle (skipped if ffmpeg absent); `ScriptedSttSession` → seq/interim/final/GoAway/error handling; bus eviction; runner isolation; WS contract via FastAPI `TestClient` websocket; metrics percentiles. A `no_network` autouse fixture patches socket creation to fail so tests cannot reach Google.
- **Frontend:** vitest for the caption merge logic and the a11y controls; `npm run build` in `make verify`.
- **Smoke (real API, on demand):** `make smoke-stt` on `samples/en_*.wav` → WER ≤ 25 %, interim p50/p95, end-of-utterance → final p50/p95, `usage_metadata` totals → `docs/metrics.md`.
- **MVP:** `make mvp-check` in fake mode (CI-safe) and in real mode at H2.
- **Docs:** `make docs-check` (settings fields ↔ configuration.md, links).
