- **2026-09-24T17:15Z · D-001-3 TTS sample rate comes from the mime type.** `gemini-3.8-flash-tts` answers at 48 kHz while the docs example (and `gemini-3.1-flash-tts-preview`) use 24 kHz; assuming 24 kHz produced a half-speed English clip that the Live STT could not follow (1 final in 50 s). - **2026-09-24T17:15Z · D-001-4 Server VAD alone finalizes late; adopt hybrid VAD next.** With 1.5 s digital-silence gaps the server finalized some sentences only at `audio_stream_end` (utterance-to-final p50 0.8 s but p95 15 s on both samples). - **2026-09-24T17:15Z · D-001-5 Free-tier quota is the owner's action item.** TTS daily quota is 10 requests per model; samples were generated across `gemini-3.8-flash-tts` and `gemini-3.1-flash-tts-preview`. Live STT works on the free tier; the scale run (M4) needs Tier 1.
- **2026-09-24T17:25Z · D-001-6 Hybrid VAD is the default.** Measured on the paid tier: hybrid gives 7/7 finals, utterance-to-final p50/p95 0.9/1.1 s and first partial p95 1.4 s versus server-only VAD p50 1.19 s with far fewer partial updates. `VAD_MODE=server` stays available for noisy rooms where a fixed RMS threshold misfires.
- **2026-09-24T17:25Z · D-001-7 TTS answers come in two shapes.** `gemini-3.8-flash-lite-tts` returns `audio/wav` (RIFF header, 24 kHz); `gemini-3.8-flash-tts` returns `audio/L16` PCM at 48 kHz. The generator decodes by mime type and always writes 16 kHz mono WAV.
- **2026-09-24T20:57Z · D-002-1 Translation transport chosen by measurement.** The docs call the Interactions API the default interface and `generateContent` legacy-but-supported. Latency is a judging criterion, so `GEMINI_TRANSLATE_API=generate_content` is the default; the Interactions path stays implemented, tested and selectable.
