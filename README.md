# Lenguaraz

*The open-source interpreter for every stage.* Pronounced *len-gwa-RAHS*.

[![License: Apache-2.0](https://img.shields.io/badge/License-Apache--2.0-blue.svg)](LICENSE)

Real-time transcription and translation for multi-track conferences: live audio from many stages in parallel, subtitles in the original language and in Spanish (plus English and Portuguese), delivered to an audience web view, production overlays and exportable files. Built on Google's Gemini audio capabilities, with an open-model path via Gemma.

> **Status:** under construction during the Nerdearla Vibeathon 2026 build window (2026-09-24 15:00 UTC → 2026-09-25 15:00 UTC). This README grows feature by feature; the full documentation set is listed in the [constitution](.specify/memory/constitution.md) (Article XVII.D).
